# Agentic Engineering — training repositories

One repository, one folder per course. Clone it once; each course is self-contained and is opened in Claude Code from its own folder.

| Folder | Course | Status |
|---|---|---|
| [`advanced/`](advanced/) | Agentic Engineering Advanced for Engineering Roles — half-day, instructor-led. The Lunch Order API, BMAD Phase 4, the ELCAi story loop. | Current |
| `basics/` | Agentic Engineering Basics for All Roles | Planned |

```bash
git clone https://bitbucket.svc.elca.ch/scm/dbl-java-agenticengineering/agentic-engineering-training.git
cd agentic-engineering-training/advanced     # then follow advanced/README.md
```

Course material lives on Confluence: ELCAIMETHOD → Onboarding → *Advanced Pre-Training Setup*.
